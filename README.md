# 📖 Overview

Dashboard CMS is a full-stack Java web application developed as both a professional portfolio project and a practical learning journey through modern backend development with Spring Boot.

The goal of this project is to build a scalable, enterprise-ready Content Management System while following industry best practices in software architecture, authentication, database design, and responsive user interfaces.

## 🚧 Phase 3 — REST API

- JWT Authentication

- CRUD Endpoints
- Pagination & Filtering
- Exception Handling

---

## 🚧 Phase 4 — React Frontend

Build a modern React application powered by the Dashboard CMS REST API.

- React Dashboard
- Protected Routes

- Responsive UI
- CMS Management Interface

Expand Dashboard CMS into a multi-platform ecosystem.

Target platforms:
